# Taskflow Todo List

A lightweight todo list made with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build step or installation is needed.

Tasks are saved in the browser's `localStorage`, so they remain available after a refresh on the same browser.

## Project structure

- `index.html` - page structure and form fields
- `css/styles.css` - responsive visual styling
- `js/app.js` - adding, displaying, updating and deleting tasks
- `js/shared/helpers.js` - reusable storage, date, ID and text helper functions
